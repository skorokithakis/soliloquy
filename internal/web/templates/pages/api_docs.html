endpoints

threads
GET /api/threads · the front page, newest activity first
thread
GET /api/threads/{id} · one thread and its comments

The thread list returns threads, page and has_next. Each page has 30 threads. Add page=2, page=3 and so on to get more. has_next is true when another page exists.

thread list fields

id
short public ID
title
the title
url
the page the thread links to; empty for a text post
link
absolute URL of the thread page
author
username, or [deleted user]
score
net votes
comment_count
number of visible comments
created_at
RFC 3339, UTC
last_activity_at
RFC 3339, UTC

thread detail fields

body
the markdown source
body_html
the rendered, sanitized HTML
edited_at
RFC 3339, UTC, or null

comment fields

id
short public ID
author
username, or an empty string on a deleted comment
score
net votes
created_at
RFC 3339, UTC
edited_at
RFC 3339, UTC, or null
body
the markdown source
body_html
the rendered, sanitized HTML
deleted
true on a placeholder for a deleted comment
replies
the comment's nested replies

A deleted comment with replies stays in the tree, so its replies keep their place. It has deleted: true and an empty author, body and body_html. A deleted comment with no replies is left out.

access

A request needs one of these: your browser session, your token as ?token=..., or a public forum.

A request with no access gets a JSON 404, not the login page. Your token is the same as your feed token. To replace it, use the reset button on your account page. The reset also changes your feed links.
